# Agent instructions

This repository holds a LangGraph factory and the Expo app it builds. Read
`docs/spec/0001-factory-and-reference-app.md` and the ADRs in `docs/adr/`
before changing anything.

## Rules

- **The spec governs.** A change implements an acceptance criterion from a
  spec, and each criterion is the name of a test. Write the test with that
  exact name.
- **Expo changes between SDK releases.** Read the `expo` major version in
  `apps/reference/package.json` and the matching docs at
  `https://docs.expo.dev/versions/v<major>.0.0/` before touching an Expo,
  Expo Router or React Native API. Add packages with `npx expo install`.
- **Never edit `android/` or `ios/`.** They are generated by
  `npx expo prebuild`. Native behaviour is configured in `app.config.ts` and
  in config plugins.
- **No secrets in the repository.** Store keys, keystores and certificates
  live in a password manager or in GitHub secrets. Only `.env.example` is
  versioned.
- **No personal data in telemetry.** Send events through
  `packages/telemetry` and add new attribute keys to its allowlist on
  purpose.
- **User-facing error text comes from the catalog** in
  `packages/error-contract`. Never render a technical message.
- **Nothing is sent to an app store without a human approval.** Submission
  lanes and factory nodes check for it. Do not work around the check.
- **A claim about a store, a license or a price cites the vendor page** it
  was read from, with the date.

## Commits and pull requests

- Conventional Commits, one line, present tense, under 72 characters:
  `feat: add checklist screen`.
- One pull request per slice. Pull requests are squash-merged, so the title
  follows the same convention.
- Versions are never edited by hand. See ADR 0004.

## Commands

```bash
npm ci                 # install every workspace
npm run lint           # eslint and prettier check
npm run typecheck      # tsc in every workspace
npm test               # unit and component tests
```
